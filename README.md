# Dissertation RAG

A research platform for investigating knowledge integrity in
Retrieval-Augmented Generation systems.

## Research focus

This project studies the detection and mitigation of adversarial poisoning
attacks against RAG-based cybersecurity systems.

## Current phase

Phase 1: Building the baseline RAG system.

## Technology

- Python 3.12
- LangChain
- Qdrant
- sentence-transformers
- OpenAI or Groq
